Parichay परिचय

A marriage biodata in two minutes. Gemma runs on this phone, so nothing you type or the photo you add is sent anywhere.

1 Tell it the details

Write the way you'd say it: Marathi, Hindi, English or a mix.

2 Check the details

Everything is editable. Fields marked check need a look: name spellings in Marathi, or a date Parichay couldn't read for sure. Blank fields are left off the biodata.

3 Layout, photo, print

Layout
